# Simple Telegram AI Bot

Минимальный Telegram-бот на `aiogram`, который пересылает текст пользователя в LLM и возвращает ответ. Работает с любым OpenAI-совместимым API, по умолчанию — через агрегатор **[polza.ai](https://polza.ai)**.

## Что делает

- `/start` — приветствие.
- Любое текстовое сообщение — отправляется в модель, ответ приходит обратно в чат.
- Нетекстовые сообщения — вежливый отказ.
- Логи пишутся в `bot.log`.

## AI: polza.ai

Бот не обращается к OpenAI напрямую. Вместо этого используется **polza.ai** — агрегатор AI-моделей с OpenAI-совместимым API:

- один API-ключ и один эндпоинт (`https://polza.ai/api/v1`) для десятков моделей (OpenAI, Anthropic, Google и др.);
- модель выбирается строкой в `AI_MODEL`, например `openai/gpt-4o-mini`;
- оплата и лимиты — на стороне polza.ai, ключ создаётся в личном кабинете;
- совместимость обеспечена клиентом `openai.AsyncOpenAI` с подменённым `base_url`.

Чтобы сменить провайдера, достаточно указать другой `POLZA_BASE_URL` и модель, поддерживающую OpenAI-формат.

## Стек

- Python 3.10+
- `aiogram` — Telegram Bot API (long polling)
- `openai` — HTTP-клиент к polza.ai
- `python-dotenv` — загрузка `.env`

## Запуск

```bash
# 1. Клонировать этот репозиторий (на вашем ПК должен быть установлен git) и перейти в проект
git clone <this-repo-url> && cd bot
# Или просто скачайте zip-архив проекта во вкладке Code вверху страницы репозитория
# Если у вас нет git или вы не хотите устанавливать его по некоторым причинам

# 2. Создать виртуальное окружение Python
python3 -m venv .venv
source .venv/bin/activate           # Windows: .venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Конфигурация
cp .env.example .env                # Переименуйте файл .env.example в .env
# отредактировать .env (см. ниже)

# 5. Запуск
python bot.py
# Или
python3 bot.py
```

Остановка — `Ctrl+C`.

## Переменные окружения (`.env`)

| Переменная           | Обязательна | Описание                                                                |
| -------------------- | ----------- | ----------------------------------------------------------------------- |
| `TELEGRAM_BOT_TOKEN` | да          | Токен вашего бота от [@BotFather](https://t.me/BotFather)               |
| `POLZA_API_KEY`      | да          | API-ключ из личного кабинета polza.ai                                   |
| `POLZA_BASE_URL`     | да          | `https://polza.ai/api/v1`                                               |
| `AI_MODEL`           | да          | ID модели из списка доступных в polza.ai, например `openai/gpt-4o-mini` |

## Структура проекта

## Заметки

- Порядок хендлеров важен: `CommandStart` зарегистрирован раньше общего `@router.message()`, иначе `/start` уходил бы в модель. Новые команды добавляйте выше общего хендлера.
- Контекст диалога не сохраняется: каждый запрос независим.
- Ошибки API логируются в консоль, пользователю ответ не отправляется.
